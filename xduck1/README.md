# Xduck 1 策略版本记录

这里按桌面提供的 v4–v11 归档 ONNX 和配套 API-v2 Python 策略脚本。以下描述来自文件名及脚本注释，展示每个版本包中的重点，不代表所有模型是严格连续训练得到的，也不代表已完成实机验证。

| 版本 | 文件与迭代重点 |
| --- | --- |
| [v4](v4/) | 同时保留刚性和柔性模型；柔性脚本组合 `flex_adapt_50` 行走与新参考姿态的 Stand 650，另有 `model_2800.onnx`。 |
| [v5](v5/) | 沿用 `flex_adapt_50` 行走，提供增量恢复站立策略及 anti-shake solver4 站立模型。脚本注释中的 Stand 2800 与包内模型文件名中的 2500 不一致，部署前需核对模型配对。 |
| [v6](v6/) | 保留 v5 方案，另加入 actor61_1500 站立策略；其站立输入使用当前反馈。新增 B80 坐下/起立模型与独立脚本。 |
| [v7](v7/) | 提供 B handoff 2500 坐下/起立模型，以及带后退停止和行走重启相关逻辑的策略与模型。 |
| [v8](v8/) | 提供 B500 站立与柔性行走组合、pushfocus 站立模型、decel teacher 行走模型，以及带 SitGovernor 的 A2600 坐下/起立方案。 |
| [v9](v9/) | 使用 V1.1.4 的 solver4 Stand 2200 与原行走映射；B handoff 坐下/起立脚本改用当前关节速度反馈。 |
| [v10](v10/) | 在 Stand 2200 组合中提供 rigid longstride 200 和 400 行走模型及对应策略脚本。 |
| [v11](v11/) | 提供 heading-start 400 行走与 head-adjust pilot32 站立模型及对应组合策略。 |

## 使用时核对

Python 文件是供部署框架调用的策略接口，不是独立的机器人驱动。具体模型选择、关节顺序、IMU 坐标、观测/动作映射与模式切换状态请以对应脚本和训练配置为准；模型名称相似并不保证可互换。部分目录包含多个候选模型，文件本身没有完整实验记录，无法据此断定最佳版本或性能提升。
