# Xduck 1 策略版本记录

这里按版本归档历史上传包 v1–v3 和桌面提供的 v4–v11，包括 ONNX 和配套 API-v2 Python 策略脚本。以下描述来自文件名及脚本注释，展示每个版本包中的重点，不代表所有模型是严格连续训练得到的，也不代表已完成实机验证。

| 版本 | 文件与迭代重点 |
| --- | --- |
| [v1](v1/) | 归档 [Walk/Stand 原始上传包](v1/xc_upload_20260921_1252/)及[五姿态标定 SitStand model 63](v1/xduck_calibrated_sitstand_20260930_model_63/)，分别提供行走/站立和坐下/起立策略。标定 SitStand 包记录的是仿真验证，尚未真机验证。 |
| [v2](v2/) | 归档 [Walk 2285](v2/xc_upload_walk2285_20260922/)及 [SitStand 2000](v2/xc_upload_sitstand2000_20261012/)；后者采用增量目标映射，并保留模型清单和验证记录。 |
| [v3](v3/) | 归档 [Walk v3](v3/xc_upload_walk_v3_20260930/)及 [Walk/Stand v5 上传包](v3/xc_upload_walkstand_v5_20261013/)，包含 `flex_adapt_50` 行走和 Stand 3100 模型。这里的 v3 是本目录的归档版本，后者保留其原始 v5 文件名。 |

| [v9](v9/) | 使用 V1.1.4 的 solver4 Stand 2200 与原行走映射；B handoff 坐下/起立脚本改用当前关节速度反馈。 |

## 使用时核对

v1–v3 的原始上传包各自保存在子目录中，归档到同一版本不代表跨包模型和脚本可互换；例如 v1 标定 SitStand 的说明记录 62 维输入，而原始 Walk/Stand 包记录 61 维输入。

Python 文件是供部署框架调用的策略接口，不是独立的机器人驱动。具体模型选择、关节顺序、IMU 坐标、观测/动作映射与模式切换状态请以对应脚本和训练配置为准；模型名称相似并不保证可互换。部分目录包含多个候选模型，文件本身没有完整实验记录，无法据此断定最佳版本或性能提升。
