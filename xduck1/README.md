# Xduck 1｜Sim-to-Real 策略迭代

本目录保存 Xduck 1 的行走、站立恢复和坐下／起立策略，覆盖归档版本 **v1–v11**。每个版本包含当时保留的 ONNX 模型、策略接口或验证资料，方便对照不同阶段的工作。

> 版本号用于整理交付文件。部分版本包含多个候选方案，不能仅凭编号判断训练继承关系或实际表现。

## 迭代路线

| 阶段 | 版本 | 主要内容 |
| --- | --- | --- |
| 基础策略 | [v1](v1/) | 初版 Walk／Stand 组合，以及基于五姿态标定的 SitStand 策略。 |
| 扩展动作 | [v2](v2/) | Walk 2285 与增量式 SitStand 2000 分别归档，补充坐下和起立方案。 |
| 行走与恢复 | [v3](v3/) | Walk v3 调整逐关节动作尺度；另收录 `flex_adapt_50` 行走与 Stand 3100 上传包。 |
| 刚柔对照 | [v4](v4/) | 分开保存刚性、柔性模型；柔性方案使用 `flex_adapt_50` Walk 和新参考姿态的 Stand 650。 |
| 站立恢复 | [v5](v5/) | 保留柔性行走，加入增量式站立恢复和 anti-shake solver4 站立模型。 |
| 反馈与坐起 | [v6](v6/) | 加入使用当前反馈的 actor61 站立策略，以及 B80 2400 坐下／起立方案。 |
| 动作切换 | [v7](v7/) | 保存 B handoff 2500 坐下／起立方案，以及后退停止、行走重启相关策略。 |
| 抗扰与减速 | [v8](v8/) | 包含 B500 站立、pushfocus 候选、柔性减速行走，以及带 SitGovernor 的 A2600 坐下／起立方案。 |
| V1.1.4 适配 | [v9](v9/) | 组合原行走映射与 solver4 Stand 2200；SitStand 接口使用当前关节速度反馈。 |
| 步幅探索 | [v10](v10/) | 在 Stand 2200 基础上提供 rigid longstride 200／400 行走候选。 |
| 航向与头部 | [v11](v11/) | 提供 heading-start 400 行走和 head-adjust pilot32 站立组合。 |

这些条目描述各目录的内容和关注点；同一行中的候选模型不一定来自同一次训练，也不意味着后一个版本已经验证优于前一个版本。

## 如何使用这些文件

ONNX 是策略模型，Python 文件负责对接部署框架中的观测和动作；请结合对应包的说明、策略脚本及训练配置选择模型。部署前应核对关节顺序和方向、IMU 坐标、观测维度、动作映射、控制周期，以及模式切换时的状态处理。

同一版本下的不同原始包是归档分组，并非自动兼容。例如 v1 标定 SitStand 包说明使用 62 维输入，而原始 Walk／Stand 包说明使用 61 维输入。v5 的脚本注释写有 Stand 2800，目录中的站立模型文件名为 2500；v3 的 Walk／Stand 上传包也保留了写有 Stand 2800 的脚本和 Stand 3100 模型。使用这些组合前应确认实际模型与接口的配对。
