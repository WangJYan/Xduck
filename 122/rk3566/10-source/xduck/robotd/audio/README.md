# Spoken system notices

Mono, 48 kHz, 16-bit PCM WAV assets, played by robotd from the release's `audio/` directory.

- `battery20.wav`: 电量不足，已低于百分之二十。
- `battery10.wav`: 电量不足，已低于百分之十。
- `init-success.wav`: 初始化成功。

Generated on 2026-11-11 with macOS `say`, installed Tingting voice, rate 170,
`--file-format=WAVE --data-format=LEI16@48000`.

These are release assets, independent of the robot's generated voice bank.
