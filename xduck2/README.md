| [v1](v1/) | 包含 `xc_walk.onnx`、`xc_standing.onnx`、`xc_site.onnx` 以及行走/站立和坐下/起立的 API-v2 脚本。行走/站立脚本标注适用于 v2.0.2 P12 Walk 与 Stand/recovery；坐下/起立脚本标注使用当前关节速度反馈。 |
